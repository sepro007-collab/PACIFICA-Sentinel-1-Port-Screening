# Data directory

`unsupervised_manifest.csv` is the audit record for the 45 exported patches. It includes the port-event identifier, grid offsets, acquisition windows, orbit pass and relative orbit, water-mask threshold, output projection, and pre/post image counts.

`preprocessing_config.json` records the six-band structure, patch dimensions, spacing, NoData value, and water threshold expected by the CNN notebook.

The GeoTIFF patches are regenerated by the acquisition notebook and are not committed by default.
